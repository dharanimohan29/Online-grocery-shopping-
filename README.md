# 🛒 Online Grocery Store Management System

The Online Grocery Store Management System is a web-based application developed using HTML, CSS, and JavaScript that allows users to browse grocery products, view details, add items to a shopping cart, and manage purchases online. The system provides a simple, interactive, and user-friendly shopping experience with organized product categories and responsive design.

## 📌 Features

* User-friendly interface
* Product listing with categories
* Add to cart functionality
* Remove items from cart
* Dynamic price calculation
* Responsive design for different devices
* Simple navigation and interactive UI

## 🎯 Objective

The main objective of this project is to develop an online platform where users can easily browse and purchase grocery items without visiting physical stores. It also demonstrates front-end web development concepts using modern technologies.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Modules

1. Home Page
2. Product Listing Page
3. Shopping Cart
4. Checkout Section
5. Navigation Menu

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The application will open in your web browser.
